# WB071 — NÃO-TESTÁVEL

Item exige derrubar `ms-sboot-auth` (`:8081`) temporariamente durante uma verificação de OTP pendente, e religar depois do teste.

## Justificativa

Mesma situação de `sgsm-ia` documentada em `evidencias/WB070.md`: `ms-sboot-auth` roda como processo Java lançado pela IDE do usuário (confirmado via `Get-CimInstance Win32_Process` — comando com `-javaagent:...idea_rt.jar`, típico de run configuration do IntelliJ), não um processo que eu iniciei ou cujo comando de start eu conheço com certeza suficiente para religar de forma idêntica depois de derrubá-lo.

Seguindo a instrução explícita da tarefa (não derrubar `sgsm-ia`/`ms-sboot-auth` sem certeza absoluta de como religá-los), este item foi marcado como `NÃO-TESTÁVEL` em vez de arriscar deixar o ambiente de dev do usuário sem o serviço de autenticação pelo resto da sessão (o que quebraria não só este teste, mas qualquer outro item pendente que dependa de `:8081`, incluindo re-execuções futuras dos itens de D/E já aprovados).

Não foi marcado o checkbox. Recomendação: mesma de WB070 — repetir com o responsável pela tarefa derrubando/religando o serviço manualmente, ou fornecendo um comando de start confiável para uma rodada futura de QA.
