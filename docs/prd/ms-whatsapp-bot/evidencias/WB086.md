# WB086 — texto com unicode/emoji

Número: `5511900000020`. Sessão preparada com consentimento aceito.

**Nota metodológica**: uma primeira tentativa em WB013 usando `curl -d '...não...'` inline em Git Bash no Windows resultou em corrupção de encoding (o shell não preservava os bytes UTF-8 corretamente ao montar o argumento `-d`). Para este item, o payload foi escrito para um arquivo `.json` com encoding UTF-8 garantido (via ferramenta de edição, não via shell) e enviado com `curl --data-binary @arquivo`, evitando o problema.
