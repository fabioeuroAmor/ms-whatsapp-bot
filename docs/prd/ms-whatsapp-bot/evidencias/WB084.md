# WB084 — campos extras/desconhecidos no JSON

## Requisição
```bash
curl -s -i -X POST http://localhost:8083/webhook/evolution -H "Content-Type: application/json" \
  -d '{"event":"messages.upsert","instance":"sgsm-bot","foo":"bar","data":{"key":{"remoteJid":"5511900000018@s.whatsapp.net","fromMe":false,"id":"WB084-1"},"pushName":"QA","message":{"conversation":"oi"},"messageTimestamp":"1700000133"}}'
```
Campo `"foo":"bar"` na raiz, não previsto no DTO.

## Resposta crua
```
HTTP/1.1 200
X-Content-Type-Options: nosniff
X-XSS-Protection: 0
Cache-Control: no-cache, no-store, max-age=0, must-revalidate
Pragma: no-cache
Expires: 0
X-Frame-Options: DENY
Content-Length: 0
Date: Mon, 24 Aug 2026 23:08:59 GMT
```

## Estado Redis
Antes: `(nil)`.
Depois:
```json
{"numero":"5511900000018","usuarioId":null,"perfil":null,"accessToken":null,"refreshToken":null,"nomeUsuario":"QA","consentimentoAceito":false,"historico":[],"confirmacaoPendente":null,"dadosCadastro":{}}
```

## Resultado
APROVADO — campo desconhecido na raiz é ignorado (`@JsonIgnoreProperties(ignoreUnknown = true)` confirmado em funcionamento), processamento segue normalmente (sessão criada).
